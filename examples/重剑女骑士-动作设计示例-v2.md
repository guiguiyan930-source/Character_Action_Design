# 重剑女骑士 · 动作设计示例 v2（符合 Schema v2）

> 本示例演示一个完整的「角色 → 动作清单 → Schema v2 动作卡」设计流水线，覆盖输入校验 → 动作包路由 → 预算 → 动作卡 → 状态机。
> **v2 升级演示**：① 5 帧关键姿势 + 帧号映射；② 一致性硬约束字段（identity_anchor / asymmetry_lock / weapon_hand_lock / palette_lock / direction_hint）；③ transitions 状态机衔接；④ 8 方向逐向描述。

## Step 1 · 动作包路由 + 预算

| 维度 | 选择 |
|---|---|
| 游戏类型 | 俯视角 ARPG → 路由 O01-O04（八方向攻击/冲刺斩/弹反/蓄力斩）+ D05（翻滚）|
| 角色定位 | 精英战场敌人（Boss 前小关守将）|
| 预算档位 | M 档 · 8-10 动作 |
| 不对称特征 | 右肩重甲 + 左眼伤疤 → 每张卡写入 asymmetry_lock |

**P0 动作清单（9 个）**：idle / walk / run / 重斩 / 突刺 / 受击 / 格挡 / 翻滚 / 倒地

| # | action_id | 模块 | 优先级 | 循环 | 帧数 | 8向? | 命中帧 | 可取消至 |
|---|---|---|---|---|---|---|---|---|
| 1 | idle | idle | P0 | loop | 16 | ✅ | - | - |
| 2 | walk | locomotion | P0 | loop | 16 | ✅ | - | - |
| 3 | run | locomotion | P0 | loop | 12 | ✅ | - | dodge |
| 4 | atk_heavy_slash | attack | P0 | one-shot | 16 | ✅ | 9 | dodge |
| 5 | atk_thrust | attack | P0 | one-shot | 16 | ✅ | 8 | dodge |
| 6 | hit_react | hit | P0 | one-shot | 8 | ✅ | - | - |
| 7 | block_hold | defense | P0 | loop | 8 | ✅ | - | parry |

## Step 2 · 风格转译（动作 DNA）

| 维度 | 关键词 | 转译 |
|---|---|---|
| 性格 冷静+坚毅 | 长预备、中速、长停顿、Ease-In-Out | 稳如钟摆，每击有蓄力定格 |
| 体型 壮硕肌肉型 | 重心低、步幅大、慢启动、微晃受击 | 巨剑挥动带全身惯性 |
| 武器 双手巨剑 | 大弧线横扫/下劈、双手举顶、挥空8+帧 | 拖剑到地收招 |
| 职业 圣殿重剑士 | 挺胸、剑指地、大开大合、格挡为主 | 举剑宣誓式招牌 |
| 心境 战意昂扬 | 死盯对手、深慢呼吸、全身绷紧 | 战斗姿态蓄势 |

**动作签名**：她永远挺胸压髋，巨剑半拖于身后，出手前有 3 帧几乎不可见的沉肩蓄力。重斩从右上劈至左下，剑尖在地面拖出 2 帧火星，收招时剑柄顿地。右肩重甲始终朝敌，左眼伤疤在侧向时可见。

## 附录 B · 下游对接要点（v2）

1. **8 方向生成**：以命中帧（F9/F1）为基准图 × direction_hint 逐向描述；NE/NW/W 可按 E/S 镜像复用（无不对称特征的角色）；本角色有不对称特征，**禁止直接镜像**，需按 direction_hint 重绘背向。
2. **16 帧生成**：以 5 帧关键姿势为节奏点（F1/F4/F9/F12/F16），中间补 tween 帧。
3. **引擎接入**：transitions 字段直接映射 Unity Animator / Godot 状态机的退出条件与取消窗口。
