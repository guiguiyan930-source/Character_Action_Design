# 角色动作设计 Skill v2

> 面向游戏 2D / 像素 / 立绘角色的**动作设计中间层**工作流。输入一份已锁定的角色设定（三视图 + 身份锚），输出可直接用于「8 方向关键姿势」与「16 帧连续动画」阶段的动作清单、动作卡与 AI 出图 Prompt。
> 兼容 GPT / Lovart / Codex / Cursor 等所有 AI Agent 平台，可直接上传 `SKILL.md` 使用。

## 🚀 快速上手

1. **填写输入**：复制 `01-输入清单` 第四节的 YAML 模板，填写角色信息（游戏类型、不对称特征为新增必填项）。
2. **校验**：`python3 scripts/validate_input.py 角色输入.yaml`，通过后进入设计流程。
3. **路由动作包**：按游戏类型（横版 ACT / ARPG / 战棋 / 塔防 / 卡牌等）查 `02-分类框架` 路由表，确定动作包候选集。
4. **产出动作卡**：按 `SKILL.md` 第七节 Schema v2 逐动作生成（5 帧关键姿势 + 四锁硬约束 + transitions）。
5. **对接下游**：动作卡直接喂给 8 方向 / 16 帧动画生成器（如 game-character-8dir-frame-animation）。

## 🔧 v1 → v2 核心变更

| 维度 | v1 | v2 |
|---|---|---|
| 动作卡 | 3 个关键姿势，无字段契约 | **Schema v2 显式声明**：5 帧关键姿势 + 帧号映射 + JSON Schema |
| 一致性 | 无硬约束，出图易镜像/换手/漂移 | **四锁硬约束**：identity_anchor / asymmetry_lock / weapon_hand_lock / palette_lock |
| 动作库 | 10 模块 48 个通用动作 | + **K-O 五类 30 个游戏行为动作**（连招/环境交互/状态异常/Boss 阶段/玩法绑定） |
| 游戏适配 | 一刀切清单 | **游戏类型 × 动作包路由表**（7 类游戏） |
| 引擎落地 | 无 | **transitions 状态机衔接**（可取消/可打断/命中帧），直接映射 Unity/Godot |
| 8 方向 | 一句话差异 | **逐向描述模板 + 镜像对称复用**（8→5 角度） |
| 防错 | 无 | **反模式清单**（8 条）+ 输入校验脚本 |
| 文件编号 | 两个 02- 冲突 | 分类框架 02- / 转译规则 03- |

## 🎮 适用游戏类型

2D 横版 ACT · 俯视角 ARPG · SLG 战棋 · 塔防 · 卡牌立绘 · MMO 社交 · 解谜探索

每类游戏都有专属动作包路由与预算档位建议（S 精简 4-6 / M 标准 8-10 / L 完整 12-16）。

---

## ⚠️ 使用要点（防踩坑）

- **有不对称特征的角色（红臂、独眼、单侧披甲）禁止在 Prompt 中写「左右镜像」**，必须逐字写入 `asymmetry_lock`。
- 每个动作卡必须携带四锁硬约束字段，缺失视为不合格。
- 战斗动作卡必须声明 `transitions`（可取消至 / 可打断 / 命中帧），否则进不了引擎状态机。
- 背向 3 视角可按镜像对称复用（8 方向只需生成 5 个角度），但有不对称特征的角色禁止直接镜像。
